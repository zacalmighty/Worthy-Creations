# Worthy Creations

Website for Worthy Creations (client of Zacharry Georges). One-page static site built on
the Bootstrapious "Agency" theme: Bootstrap, jQuery, Owl Carousel, Lightbox.

- **Live:** hosted on Netlify (see `netlify.toml`); domain managed by Zac
- **Contact form:** posts to Formspree (`https://formspree.io/f/...` in `index.html`)
- **Local preview:** open `index.html`, or `npx serve .` → http://localhost:3000
- **Edit:** content is in `index.html`; style overrides go in `css/custom.css` (keep
  `css/style.default.css` as the theme original). Theme credits in `readme.txt`,
  `credits.txt`, `license.txt`.

Deploys: every push to `main` publishes to the live site; pull requests get a Netlify
preview link.
